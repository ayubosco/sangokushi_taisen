# Token 實卡比例＋己城底帶（歸城／出陣）— Design 2026-09-11

**Bosco：** 跟番大戦實卡同戰場比例；武將太大；要知回城回血再出。  
**Research：** `arcade-card-battlefield-proportion.md`（54×86mm ≈ 5:8）。

## 1. Token（Design lock）

| 項 | 鎖 |
|---|---|
| 長寬比 | **5:8**（跟實卡；**廢 3:4**） |
| 場上短邊寬 | ≈ **拖場寬 14–18%**；相鄰中心距 ≥ ~1.3× token 寬 |
| 舊「縮 70–80%」 | 只係過渡語 — **以 14–18% 場寬＋5:8 為準** |
| 選中 ring | 跟卡縮 |
| Detail | Detail 彈層可大圖；**場上**保持細＋瘦卡 |

## 2. 己城底帶（視覺）

| 項 | 鎖 |
|---|---|
| 位置 | 可拖盤 **最底一橫帶**（己方側），正交鳥瞰 |
| 高度 | 約可拖高 **10–14%** |
| 語彙 | 黑漆＋淡金邊；入帶 **己城高亮**＋飛字「返城」 |
| 歸城 | 拖 token **入**底帶 |
| 出陣 | 拖 token **出**底帶上戰場 |
| 敵城 | 對側頂薄帶＝攻城接觸；唔搶中場助走 |

底掣「歸城／出陣」只輔；**主操作＝拖帶**。
