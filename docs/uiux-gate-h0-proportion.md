## 為何急

## 預設推方案 A（等 Bosco 拍）

| 區 | 佔屏高 |
|---|---|
| 頂 HUD | ≤6% |
| Watch 只讀（雙方全場） | **15–18%**（≤20%） |
| 城條 | 3–4% |
| **可拖戰場** | **≥58–62%**（驗收 ≥55%） |
| 底掣 | 8–10%（計略≥12mm） |
| tip | 疊場可略過，唔永久食高 |

方案 B（後備）：Watch 改右上 PiP，場更大——Bosco 要先講。

---

## Acceptance（截圖量度）

量法：可拖區外框高 ÷ 全屏高；可拖寬÷高。

- [ ] 可拖高／屏高 **≥ 0.55**（Fail <0.50）
- [ ] 可拖寬／高 **≥ 0.85**（唔極扁絲帶）
- [ ] Watch 高／屏高 **≤ 0.20**
- [ ] 上區仍只讀（無可點主操作）
- [ ] 下盤己＋敵同盤；敵深描邊＋敵向箭
- [ ] 底掣中文仍在；計略唔被場擠到 <12mm

Backend 改 constraint 前後各截一幀標 %；UIUX 勾 H0 Pass 先開下一刀「手指＝卡」token。
