# 2D 盤兵種 Sprite Sheet — Design 2026-09-11

跟 Bosco／Sango：sprite sheet 做攻拳；FB「靜圖→連環幀」思路。  
跟 `design-portrait-anim-layers.md`。**唔發明幀秒／數值。**

## 原則

| 項 | 鎖 |
|---|---|
| 範圍 | **按兵種**共用 sheet（騎／槍／弓／刀｜攻城預留）——**唔**一開始 14 將各出全套 |
| 將面 | 靜態肖像／頭貼上 token 或 sheet 頭位（Cost6 日系半身） |
| FX | オーラ／槍尖光／箭線／飛字＝**獨立層**（`a-fx-*`），唔畫死喺 sheet |
| 底 | 每幀 **透明** 或漆黑；淨人物＋武器／配件 |
| 播 | Backend Flame `SpriteAnimation`；C 窗仍跟 A 鎖（≥1C オーラ等） |

## v1 姿態清單（每兵種一張 sheet）

建議格：**4 行 × 4–6 列**（可調）；每格同尺寸；左→右＝動畫序。

| 行 | 姿態 | 用途 |
|---|---|---|
| 1 | **待機** idle | 呼吸／微動 loop |
| 2 | **移動** move | 拖／助走 |
| 3 | **攻擊** attack | 騎＝突撃衝刺姿；槍＝刺／迎撃架；弓＝拉射；刀＝揮砍 |
| 4 | **特殊／收** | 騎收勢；槍擋後；弓放箭後；或 撤退／返城 簡姿 |

弓另加：**蓄勢** 可併入 attack 前 1–2 格（企穩）。攻城黃條仍用 UI／FX，唔靠 sheet。

## 格線（初稿，Backend 可改 px）

- 單格：**256×256** 或 **128×128**（場上小用 128；高清出 256 再縮）  
- Sheet：**1024×1024**（4×4）或 **1536×1024**（4×6）  
- 錨點：腳底中心（騎＝馬蹄中）——方便對齊 3:4 卡 token 底

## 出圖優先序

1. **槍** sheet（迎撃／槍尖最關鍵）  
2. **騎** sheet（突撃）  
3. **弓** sheet（停射）  
4. 刀／攻城預留  

每張：透明底 PNG sheet ＋一行說明「列＝幀序」。

## 禁

全屏 cut-in sheet；場景背景；一將一 sheet 爆量；用 sheet 取代 C 窗預兆。
